Safety gates

01 / No broker execution

Exness/MT5 is not connected. No API key can enable live orders in this build.

02 / Data quality

Provider timestamps and missing feeds are shown. Signal scores are transparent rules, not a trained or backtested model.

03 / Scale-in policy

Paper engine now simulates signal entries/exits on an estimated ATR risk-unit basis. Costs are estimated, not actual CFD spread. Historical replay is technical-only; no news-event replay or guaranteed 24/5 uptime.
